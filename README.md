# VJster

Stream Deck control of the playback speed and the picture quality of the video
playing in your own browser. A Stream Deck plugin and a Chrome extension talk
over a loopback socket on your machine; a later phase drives a page inside an
OBS browser source from the same keys and dials.

Status: Phase 0, project skeleton. Nothing to install yet. The design is in
[REQUIREMENTS.md](REQUIREMENTS.md) and the build order in [PLAN.md](PLAN.md).

Everything runs locally. No accounts, no cloud, no telemetry.
