# VJster

Stream Deck control of the playback speed and the picture quality of the video
playing in your own browser.

**Development moved on 2026-10-30** into the Fadester for OBS repository,
[jbrick2070/streamdeck-fadester](https://github.com/jbrick2070/streamdeck-fadester),
where the documents live in `docs/vjster/` and the code in `src/vjster/`
(moved in commit 59d33c3). The
VJster deck actions ship there first, inside Fadester for OBS; a standalone
VJster plugin is planned from the same source later.

This repository keeps the first two steps as they were done here:

- Phase 0, the approved requirements and plan, and the project skeleton.
- Phase 1 step 1, the probe of the YouTube player API
  (`scripts/probe-player-api.js`) and the documents updated from its results.

The current documents are the ones in the Fadester repository. Nothing here is
deleted; whether this repository later holds the standalone build's releases
or is archived is decision D-9 in the moved requirements.
